# UI-006 — dire qu'une écriture a réussi

## Le défaut

**Trente-six contrôleurs mettaient en session un code que rien ne partageait et
qu'aucun écran ne lisait.**

`->with('status', 'release.ready')` déposait une chaîne dans la session. Le
middleware Inertia partageait `success` et `error` — et jamais `status`. Aucun
composant ne lisait `status`. Et rien, nulle part dans la plateforme, ne pose
`success` ni `error`.

Donc **chaque écriture réussie de l'interface redirigeait en silence** :
démarrer un import, promouvoir un candidat, enregistrer des crédits, marquer une
sortie prête — et **remettre une sortie à un distributeur, le seul acte qui ne
peut pas être défait**. La seule façon pour un opérateur de savoir que cela avait
marché était d'aller voir.

Dix des phrases existaient déjà. Elles avaient été écrites par des tickets
antérieurs, dans six langues, et montrées à personne : `ui.settings.saved`
disait « Saved. » à une pièce vide. Les vingt-six autres codes n'avaient aucune
traduction — donc même câblés, ils auraient affiché un identifiant pointé.

## Ce que fait ce changement

Trois lignes de câblage, et la copie qui manquait.

**Le code voyage, jamais la phrase.** Un contrôleur qui aurait mis en session
une phrase anglaise donnerait à un lecteur portugais une confirmation en anglais
pour la chose qu'il a le plus besoin d'avoir comprise. Le shell traduit
`ui.flash.<code>` dans la langue active.

**Une seule maison pour les trente-six.** Le catalogue est indexé par le code
lui-même, points compris — c'est ce qui rend l'ensemble énumérable, et donc
vérifiable. Les dix phrases dispersées ont été déplacées là : une chaîne dans
deux fichiers est une chaîne qui dérive.

## Le test qui compte

`SuccessIsAnnouncedTest` lit **chaque `with('status', …)` de `src/`** et exige
une ligne pour chacun, dans les six langues. C'est ce qui rend une *nouvelle*
confirmation silencieuse impossible, plutôt que de simplement réparer les
trente-six qui existaient.

Il vérifie aussi le défaut vu de l'autre côté : une phrase du catalogue que
personne ne met en session est une phrase que six traducteurs entretiennent pour
un message que personne ne verra jamais.

Les écrans Blade — connexion, installateur — sont exclus explicitement : ils
traduisent côté serveur avec `__()`, lisent `session('status')` directement, et
ont toujours affiché leur message. Le scanner les reconnaît à leur appel de
traduction plutôt qu'à une liste tenue à côté.

## Vérification

6 tests PHP, 2 tests de composant. 5 mutations, 5 tuées : le code non partagé,
une phrase retirée d'une seule langue, une phrase orpheline ajoutée au
catalogue, un nouveau code sans traduction, et le shell affichant le code brut
au lieu de la phrase.
